# Pragmatic Design Patterns Protocol

1. Use Strategy pattern to swap algorithms dynamically without modifying client code.
2. Use Adapter pattern to normalize incompatible third-party interfaces.
3. Avoid pattern over-engineering; apply patterns only when real complexity demands abstraction.
