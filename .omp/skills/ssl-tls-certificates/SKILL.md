# SSL/TLS Security Protocol

1. Automate renewal via Certbot/ACME 30 days before expiration.
2. Enforce TLS 1.3 as standard, disabling TLS 1.0 and 1.1.
3. Implement mutual TLS (mTLS) for zero-trust service-to-service communication.
