# LLM Prompt Engineering Protocol

1. Structure prompts with clear roles, constraints, examples, and output schemas.
2. Use XML tags (<context>, <instruction>, <schema>) for unambiguous parsing.
3. Request Chain-of-Thought reasoning for complex logic before generating final output.
