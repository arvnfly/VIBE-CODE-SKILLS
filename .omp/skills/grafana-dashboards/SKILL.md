# Grafana Dashboard Protocol

1. Design around the 4 Golden Signals: Latency, Traffic, Errors, Saturation.
2. Use template variables ($environment, $service) for reusable multi-tenant dashboards.
3. Highlight service degradation thresholds clearly with warning bands.
