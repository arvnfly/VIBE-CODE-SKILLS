# README Craft & Open Source Presentation Protocol

1. Above-the-fold clarity: 1-sentence value proposition, badges, quickstart one-liner.
2. Provide runnable copy-paste examples within 30 seconds of reading.
3. Include architectural diagram and clear contribution guidelines.
